# Renault Laguna II for BeamNG.drive

A community project recreating the Renault Laguna II (X74, 2001–2007) as a configurable vehicle for BeamNG.drive.

> **Development status:** The project provides a generated, testable mod, but it has not yet been fully verified inside BeamNG.drive. Engine sounds and a detailed animated interior are not yet implemented.

## Highlights

- Eight engine choices with fuel-specific torque curves
- Five- and six-speed manuals; four- and five-speed automatics
- Standard, sport, and lowered suspension options
- Open and limited-slip front differentials
- Standard and large brake options
- 15-inch steel and 17-inch alloy wheels
- Halogen and xenon headlights
- Factory and smoked tail lights
- Multiple glass, mirror, wiper, moulding, plate, badge, and sensor options
- Eleven period paint choices plus the BeamNG paint picker
- Six ready-made vehicle configurations

## Installation

### Install a packaged mod

If `renault_laguna.zip` is available:

1. Close BeamNG.drive.
2. Open the BeamNG launcher and select **Manage User Folder > Open in Explorer**.
3. Copy `renault_laguna.zip` into:

   ```text
   %LOCALAPPDATA%\BeamNG.drive\<version>\mods\
   ```

4. Restart BeamNG.drive and select Renault Laguna in the vehicle selector.

### Install directly from the repository

Copy `vehicles/renault_laguna` to:

```text
%LOCALAPPDATA%\BeamNG.drive\<version>\mods\unpacked\laguna\vehicles\renault_laguna\
```

Keep the `.dae`, `.jbeam`, `.pc`, `info*.json`, and `materials.json` files together inside `renault_laguna`.

## Build from source

Requirements:

- Windows
- Python 3
- Blender 5.3 or a compatible Blender executable
- BeamNG.drive for final in-game testing

Set the Blender executable when needed:

```powershell
$env:BLENDER="C:\Program Files\Blender Foundation\Blender 5.3\blender.exe"
```

Build, validate, render, and package the complete mod:

```bash
python tools/build_all.py
```

For development without renders:

```bash
python tools/build_all.py --no-renders
```

The package script creates:

```text
renault_laguna.zip
```

JBeam files are generated by `tools/beamng/gen_laguna2.py`. Edit the generator, not generated `.jbeam` files.

## Known limitations

- Estate and Phase 2 bodies are planned but not implemented.
- The interior is static and has limited detail.
- Engine sounds and interior-camera configuration are absent.
- Glass is not yet breakable.
- Doors, hood, tailgate, bumpers, and exterior panels are not detachable.
- Some wheel, tyre, steering, and physics values still need verification in BeamNG.drive.

See [CUSTOMIZATION_STATUS.md](CUSTOMIZATION_STATUS.md) for the detailed implementation table.

## Contributing

Update source generators or Blender scripts rather than generated JBeam files. Run:

```bash
python tools/beamng/gen_laguna2.py
python tools/beamng/validate.py
```

Before submitting changes that affect physics or vehicle compatibility, test the result in BeamNG.drive and include the game version, configuration used, and relevant logs.
